dagm

This is a project I started working on after reading Inigo Quilez' article on generating color palettes using the cosine function. The idea is to map the unit interval $x$ through the expression $\alpha + \beta \cos{\gamma x + \delta}$, where the parameters $\alpha$, $\beta$, $\gamma$, $\delta$ all range from 0 to 1.

     Running dagm 0.0
